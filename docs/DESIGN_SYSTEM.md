# Unity Engineering V3 design system

The existing orange geometry remains the only brand mark. The primary composition pairs an anchored editorial headline with industrial imagery and a graphite navigation bar. White and steel-coloured catalogue surfaces give equipment silhouettes room to read. Orange is reserved for live controls, focus and small accents.

| Role | Design decision |
| --- | --- |
| Palette | Graphite #101720, industrial navy #151f2c, warm paper #f4f4f0, dark copy #17212b, steel #687581, mark and main action #ff5500. |
| Type | Space Grotesk for headlines, Inter for body copy and IBM Plex Mono for technical labels, with local system fallbacks. Use large type with short line lengths. |
| Grid | Fluid central gutter with an ultra-wide cap. Composition shifts from two editorial columns to a single reading order on small screens. |
| Media | A first-fold scene, boxed studio equipment, a fabrication story grid and a separate proof/inspection feature. Preserve full equipment silhouettes. |
| Buttons | Rectangular filled and outline treatments, clear link labels and visible focus. The main page action comes first. |
| Specifications | Row-based definition lists pair a technical term and the unit, requirement or confirmed value. |
| Interaction | Native disclosure, tabs implemented with buttons, platform dialog, keyboard focus and optional WebGL. |
| Density | The catalogue prioritizes machine name, context, sizing and direct links. Editorial spreads use stronger separation between subjects. |

Company, product and category routes share this system through static page templates. The installed type assets carry bundled OFL notices where present.
